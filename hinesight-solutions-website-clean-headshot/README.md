# Hinesight Solutions Website

This is a live-ready static website package for Hinesight Solutions.

## Files included

- `index.html` — main homepage
- `styles.css` — full website styling
- `script.js` — mobile menu and scroll animations
- `privacy.html` — starter privacy policy placeholder
- `terms.html` — starter terms page placeholder
- `assets/headshot-placeholder.svg` — placeholder image
- `assets/office-bg.svg` — subtle office background illustration

## Before publishing

1. Replace the placeholder headshot with a real image of James.
2. Update testimonials with real approved testimonials.
3. Review privacy/terms pages for legal/compliance accuracy.
4. Replace `https://your-domain.com` inside `index.html` schema markup with your real domain.
5. Add your real social media profile links in the footer.
